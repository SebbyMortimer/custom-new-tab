# Sebby's Custom New Tab Page

This is my custom web page for when you open a new tab in your browser. It's an ocean/iceberg themed one featuring Piplup (and also CHARLES) that gives me a gentle reminder to slow down. Also, if you click on Charles it'll play chill music from Lego Jurassic World if you were wondering where that was from.

You can try out the page [here](https://sebbymortimer.co.uk/custom-new-tab/).



## How to run it locally

To run it locally, just clone the repo and if you open index.html in a browser everything besides the YouTube video will work, however if you would like to get the YouTube video embed working you need to run a local dev server at least. (eg using Python or Vite)
